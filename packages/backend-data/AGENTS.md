# Edge-Git — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

- All D1 access via DAOs over `D1Queryable`: `BaseDAO` (`withRetry` + static `findById`/`deleteOlderThan` + instance `findRowById`/`deleteRowsOlderThan`/`encodeCursor`/`decodeCursor`), `RepositoryDAO` (case-insensitive owner/name, `owner_type/owner_ci/name_ci/org_id`, `listByOrgId/listByCollaboratorEmail/renameOwner`; `getByOwnerAndName` wraps non-schema failures as `DatabaseError` so git auth maps outages to 503, never a confusing 500), `UserDAO` (`upsertUser`/`getByEmail` + `username`, `getByUsernameCi/setUsername`), `NamespaceDAO` (global `user|org` registry: `claim/claimIgnore/release/isTaken`), `OrganizationDAO`/`OrganizationMemberDAO` (`owner|member`, `countOwners`), `RepoCollaboratorDAO` (`admin|write|read` grants), `UserAccessTokenDAO` (hash lookup, expiry prune, per-user list), `IssueDAO` (+ `CommentRow`, per-repo numbering via `COALESCE(MAX(number))`), `PullRequestDAO` (numbering + reviews/comments + `pull_review_threads`/`pull_thread_comments` + review dismissal columns; `listThreads`/`getThread` degrade to empty on legacy DBs), `ReleaseDAO` (`releases`/`release_assets` + `deleteByRepo`), `SearchDAO` (`repo_fts`/`issue_fts`/`pull_fts`/`code_fts` first, LIKE fallback; token/FTS/LIKE builders in `SearchQueries.ts`, same `*Queries.ts` pattern as `CollaborationQueries`).
- Utils: `D1Types` (`D1Queryable`), `D1Utils` (`executeD1WithRetry`), `D1ErrorClassifier` (retryable detection), `CursorUtil` (opaque pagination cursors), `CollaborationQueries` (pure SQL builders) + `computeUnixCutoffSeconds/computeDateCutoffIso/pruneInBatches` (shared retention/batching helpers). No `constants/` or `crypto/` modules — hashing lives in `@edge-git/shared/utils` (`CryptoUtil.sha256Hex`).
- Migrations in `migrations/0021_squash.sql` (single baseline squashed from 0001–0020: `users`/`namespaces`/`organizations`/`organization_members`, `repositories` + `repo_collaborators`, `user_access_tokens` with scopes/prefix, `issues`/`comments`, pulls (`pull_requests` + reviews/comments/threads/dismissal), `branch_protection_rules`, social (`repo_stars`/`repo_watches`/`repo_events`/`notifications`), collab (`labels`/`milestones`/assignees/reviewers), FTS (`repo_fts`/`issue_fts`/`code_fts` rowid-linked/`pull_fts`/`discussion_fts`/`snippet_fts` + triggers), `repo_webhooks`/`webhook_deliveries`, `releases`/`release_assets` metadata only (bytes in the DO), surfaces (`projects`/`discussions`/`wiki`/`snippets`), `teams`/`team_members`/`team_repo_grants` + `audit_logs` with org/repo scoping indexes, transfer (imports/mirrors/`deploy_keys`/`token_repo_grants`/`repo_security_settings`), `check_runs`, numbering UNIQUE backstop + `repo_number_counters`); `migrations/0022_normalize.sql` adds 3NF junction tables (`token_scopes`/`webhook_events`/`branch_protection_required_checks`/`repo_import_refs`, additive — legacy JSON columns still authoritative); integration embeds all `*.sql` via `__INTEGRATION_MIGRATION_SQL__`. New DAOs: `TeamDAO`/`TeamMemberDAO` (`admin|member`, `countAdmins`)/`TeamRepoGrantDAO` (`deleteByTeam/deleteByRepo`), `AuditLogDAO` (`create`/`query` cursor-paginated with `resourcePrefix` + `queryOrgAudit` + `pruneOlderThan`).
- `src/dao/NumberingDAO.ts` — atomic per-repo numbering (`repo_number_counters`, migration 0021): single UPSERT ... RETURNING hands out distinct numbers under concurrency, seeded from `MAX(number)`; throws missing-schema-style when the table is absent so services fall back to the legacy loop.
- Token prune path: `UserAccessTokenDAO.pruneExpired(now, limit)` called from `TaskRegistry.pruneExpiredTokens`; retention constants come from `ConfigurationManager`, never hardcoded in DAOs.
- Layer 2 (L0-only): import only `@edge-git/shared` + `@edge-git/backend-errors`; never `backend-runtime`, `git-*`, `backend-services`, or `apps/*` (enforced by `no-restricted-imports`).
