# Edge-Git — Backend Data (D1/DAO Layer)

Scope: `packages/backend-data/**`. Parent index: `../../AGENTS.md`.

- All D1 access via DAOs over `D1Queryable`: `BaseDAO` (`withRetry` + static `findById`/`deleteOlderThan` + instance `findRowById`/`deleteRowsOlderThan`/`encodeCursor`/`decodeCursor`), `RepositoryDAO` (case-insensitive owner/name, `owner_type/owner_ci/name_ci/org_id`, `listByOrgId/listByCollaboratorEmail/renameOwner`), `UserDAO` (`upsertUser`/`getByEmail` + `username`, `getByUsernameCi/setUsername`), `NamespaceDAO` (global `user|org` registry: `claim/claimIgnore/release/isTaken`), `OrganizationDAO`/`OrganizationMemberDAO` (`owner|member`, `countOwners`), `RepoCollaboratorDAO` (`admin|write|read` grants), `UserAccessTokenDAO` (hash lookup, expiry prune, per-user list), `IssueDAO` (+ `CommentRow`, per-repo numbering via `COALESCE(MAX(number))`), `PullRequestDAO` (numbering + reviews/comments + `pull_review_threads`/`pull_thread_comments` + review dismissal columns; `listThreads`/`getThread` degrade to empty on legacy DBs), `ReleaseDAO` (`releases`/`release_assets` + `deleteByRepo`), `SearchDAO` (`repo_fts`/`issue_fts`/`pull_fts`/`code_fts` first, LIKE fallback; token/FTS/LIKE builders in `SearchQueries.ts`, same `*Queries.ts` pattern as `CollaborationQueries`).
- Utils: `D1Types` (`D1Queryable`), `D1Utils` (`executeD1WithRetry`), `D1ErrorClassifier` (retryable detection), `CursorUtil` (opaque pagination cursors), `CollaborationQueries` (pure SQL builders) + `computeUnixCutoffSeconds/computeDateCutoffIso/pruneInBatches` (shared retention/batching helpers). No `constants/` or `crypto/` modules — hashing lives in `@edge-git/shared/utils` (`CryptoUtil.sha256Hex`).
- Migrations in `migrations/0001_squash.sql` (`repositories`, `users`, `user_access_tokens`, `issues`) + `migrations/0002_permissions.sql` (additive: `username` cols, `namespaces`, `organizations`, `organization_members`, `repo_collaborators`, `owner_type/owner_ci/name_ci/org_id`) + `0003_pull_requests.sql` + `0004_forks.sql` + `0005_search.sql` (`repo_fts`/`issue_fts`) + `0006_code_search.sql` + `0007_security.sql` (scopes, `branch_protection_rules`) + `0008_social.sql` + `0009_collab.sql` + `0010_pr_threads.sql` (threads + review dismissal) + `0011_pull_search.sql` (`pull_fts`) + `0012_webhooks.sql` (`repo_webhooks`/`webhook_deliveries`) + `0013_releases.sql` (`releases`/`release_assets` metadata only; bytes in the DO) + `0015_teams_audit.sql` (`teams`/`team_members`/`team_repo_grants`, `audit_logs` with org/repo scoping indexes) + `0017_checks.sql` + `0018_code_fts_rowid.sql` (rowid-linked `code_fts` triggers: FTS maintenance by `rowid` point lookup instead of `(repo_id, path)` scan); integration embeds all `*.sql` via `__INTEGRATION_MIGRATION_SQL__`. New DAOs: `TeamDAO`/`TeamMemberDAO` (`admin|member`, `countAdmins`)/`TeamRepoGrantDAO` (`deleteByTeam/deleteByRepo`), `AuditLogDAO` (`create`/`query` cursor-paginated with `resourcePrefix` + `queryOrgAudit` + `pruneOlderThan`).
- `src/dao/NumberingDAO.ts` — atomic per-repo numbering (`repo_number_counters`, migration 0020): single UPSERT ... RETURNING hands out distinct numbers under concurrency, seeded from `MAX(number)`; throws missing-schema-style when the table is absent so services fall back to the legacy loop.
- Token prune path: `UserAccessTokenDAO.pruneExpired(now, limit)` called from `TaskRegistry.pruneExpiredTokens`; retention constants come from `ConfigurationManager`, never hardcoded in DAOs.
- Layer 2 (L0-only): import only `@edge-git/shared` + `@edge-git/backend-errors`; never `backend-runtime`, `git-*`, `backend-services`, or `apps/*` (enforced by `no-restricted-imports`).
