# Edge-Git — Backend Services

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Layer 3 (may use layers 0–2 only, never apps).

- Domain map:
  - `src/auth/AccessAuthService.ts` — `/user/*` identity: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access.getIdentity()` fallback. Never trust `Cf-Access-Authenticated-User-Email`.
  - `src/auth/TokenService.ts` — PATs: `sha256("edge-git-pat:" + token)`, `MAX_TOKENS_PER_USER` (default 5), `MAX_TOKEN_EXPIRY_DAYS`; mint/authenticate (`authenticateWithPAT` → `{email, scopes}` + `last_used_at` touch)/list/revoke. Scopes (`TokenScopes.ts`: `repo:read|repo:write|admin`, `admin` > `write` > `read` hierarchy, legacy NULL rows = full) are git-only: fetch needs `repo:read`, push needs `repo:write` (enforced in `gitAuthForRepo`).
  - `src/protection/BranchProtectionService.ts` — per-repo `*`-glob rules (longest match wins): `require_pr`, `required_approvals` 0–6 (creator self-approval excluded, `checkMergeBlocked` shared by same-repo + cross-fork merges; dismissed reviews never count), `block_force_push`/`block_deletion` (DO-enforced via RPC protections), CODEOWNERS quorum (resolved owners for the changed paths need one non-creator owner approval), `require_status_checks` stored-but-ignored. `MAX_RULES_PER_REPO` (default 10).
  - `src/repo/RepoService.ts` — repo CRUD facade by `(owner, name)` (case-insensitive): delegates visibility (`requireRole`/`listVisibleForUser`/`getRole`) to `RepoVisibilityService`; `validateNames` delegates to shared `RepoFullName` (the old `normalizeOwner/normalizeRepo` statics were removed — routes import `RepoFullName` from `@edge-git/shared/utils` directly); limits via injected `AppConfiguration` (`getMaxReposPerUser`); org-create allowed for owners + members; delete cascades via `repoCleanup`.
- `src/repo/RepoVisibilityService.ts` — read-model visibility facade (reusable from search/realtime/route guards without the write path).
  - `src/user/UserService.ts` — `upsertUser` (lowercased email, idempotent; bootstraps globally-unique `username` from email prefix + `namespaces` claim) + `getProfileByEmail/getByUsername/renameUsername` (validates `OWNER_RE`, cascades `repositories.owner`, frees old name immediately).
  - `src/org/OrganizationService.ts` — org CRUD + `owner|member` management: `createOrganization` (global-namespace check), `requireOwner/requireMember`, `addMember/setMemberRole/removeMember` (last-owner guard), `rename` (cascades repos), `disband` (blocked while repos exist), `resolveEmail(usernameOrEmail)`. Slug rule imports canonical `SLUG_RE` from `@edge-git/shared/utils` (re-exported as `ORG_NAME_RE` for compat).
  - `src/team/TeamService.ts` — org-scoped teams (`admin|member`, `MAX_TEAMS_PER_ORG`/`MAX_TEAM_MEMBERS`/`MAX_TEAM_GRANTS`): create/rename/delete (org-`owner`-only, manual cascade), member mgmt (org owner or team `admin`, last-admin guard), repo grants (`admin|write|read` per team→repo, org-`owner`-only), `listMemberEmails` for CODEOWNERS `org/team` expansion. Slug rule imports canonical `SLUG_RE` (re-exported as `TEAM_SLUG_RE` for compat).
  - `src/audit/` — `AuditService` facade (`buildRequestEvent` + `record` fan-out that never throws + `queryByOrg` owner-only + `queryMine` + `pruneOlderThan`), `AuditObserverRegistry` (`withDefaults`/`withObservers` test seam, wired as `Tokens.AuditObserverRegistry` in the composition root so observers inject via container), `AuditEventBuilder`, `AuditPayloadBuilder` (`resolveAction` METHOD:path→action map, IP/UA, path-derived `resource`).
  - `src/permission/PermissionService.ts` — central `getRole(viewerEmail|null, repo)` → `admin|write|read|null`: org owners implicit admin, members/outsiders via `max(repo_collaborators grant, team_repo_grants where viewer is a member of the same-org team)`, anon read-only on public. Team grants load batched (one grant list + one concurrent team/membership fan-out, positional membership so legacy rows without `team_id` still resolve). `strictSchema` (wired true in production via `isBypassAllowed`) turns missing-table degrades into `DatabaseError` (fail closed); non-prod keeps legacy degrade. Used by git auth, public visibility, repo/issue guards.
- `src/numbering/numberAllocator.ts` — `allocateNumberWithFallback` shared by issue/pull/discussion/project creates: atomic `NumberingDAO` first, legacy `MAX+1` only on missing-table/fake-DB errors (fail-closed: unknown-entity and genuine D1 errors rethrow instead of masking behind a legacy read; 0019 UNIQUE + 3-retry stays the backstop).
- `src/errors/` — AWS-parity error pipeline: `ErrorMapper` (`mapServiceError` → `{Exception:{Type,Message}}`, `hideExistence` for private resources, `failClosed` for auth reads) + `ErrorTranslationUtil` (domain → HTTP payload) + `ErrorDeserializationUtil` (HTTP → typed `ServiceError`, lenient legacy `{error,message}` + plain-text compat for the web client).
  - `src/issue/IssueService.ts` — per-repo auto-numbering (`MAX(number)+1`), newest-first `listByRepo`. Triage (`updateStatus`) requires `write+` (enforced in routes via `requireRole`).
  - `src/pull/PullRequestService.ts` — PR CRUD + reviews/comments + inline threads (`openThread/replyThread/resolveThread`, path/line/side validation, 10k body caps) + `dismissReview` (`write+` in routes; dismissed reviews stay visible but leave `isBlockedByReviews`/quorum). Pure helpers live in `PullReviewGate.ts` (`isBlockedByReviews`/`isDismissed`, unit testable without D1); branch validation imports canonical `isValidBranchName` from `@edge-git/shared/utils`.
  - `src/collab/Codeowners.ts` — `parseCodeowners/matchCodeowners` + `normalizeCodeownerHandle` (`@user`→username, emails pass through, malformed→null) + `parseCodeownerTeam` (`org/team`→member-email expansion via `TeamService`).
  - `src/search/SearchService.ts` — `searchRepos/searchIssues/searchPulls/searchCode` (`sanitizeQuery` 2–200 chars, `clampLimit` ≤50, over-fetch ×3 then `PermissionService` visibility filter).
  - `src/webhook/WebhookService.ts` — hook CRUD (`MAX_HOOKS_PER_REPO` default 10): URL SSRF guard (http/https, no credentials, no literal loopback/private hosts), event subset of `WEBHOOK_EVENTS`, per-hook unique signing secret (auto-generated or caller-provided 16–256 chars; masked in lists, once on create/rotate).
  - `src/webhook/WebhookDeliveryService.ts` — at-least-once fan-out: `enqueueForEvent` (active + subscribed hooks only, never throws), `processDue` (optimistic per-row claim, `AbortSignal` timeout, HMAC `X-EdgeGit-Signature-256`, retry 429/5xx + network with 1m→24h backoff via pure `WebhookRetryPolicy.ts`, `WEBHOOK_MAX_ATTEMPTS` default 5, hook auto-disable after `WEBHOOK_MAX_CONSECUTIVE_FAILURES` default 20), `sendTestPing` (inline `ping`), `redeliver`, prune passthrough.
  - `src/release/ReleaseService.ts` — tag-backed releases (`TAG_NAME_RE` git-safe, drafts default, `MAX_RELEASES_PER_REPO` default 20) + asset metadata (`MAX_ASSETS_PER_RELEASE` default 10, `MAX_ASSET_BYTES` default 25MB, sha256-verified); bytes live in the `RepoWorker` DO (`/release-assets`), D1 holds metadata only. Events `release_created`/`release_published` map to the `release` webhook event.
  - `src/realtime/RealtimeService.ts` — live-update ticket authorization: `authorizeRepoChannels` (private hides existence → 404 without `read+`, inbox tags never granted on repo shards) + `inboxSubscription` (self hash only) + `inboxHashForEmail`/`hashRecipients` (sha256 email tags for the global inbox shard).
- `src/composition/` — `Tokens` registry (`tokens.ts`: `Env/Db/Keys/AppConfig`, DAO factories, services) + `createRequestScope(env)` (`requestScope.ts` orchestrator; DAO tables in `daoBindings.ts`, service wiring in `serviceBindings.ts`, shared env/factory in `serviceFactory.ts`): per-request `Container`, table-driven lazy+memoized DAO factories (no Secrets Store round-trip until used), single `PermissionService` binding (dependents resolve via container, never `new`), lazy `AppConfig`. Handlers resolve `scope.get(Tokens.X)`; the old `*Factory` shims were removed.
- Constructor injection: every service takes `(env, deps?)` with `() => Promise<DAO>` factories defaulting to real DAOs + optional `permissionService` thunk + `config?: AppConfiguration` — tests override with fakes (see `test/composition.test.ts`), no module mocks needed.
- Errors via `@edge-git/backend-errors` (`Bad/Unauthorized/Forbidden/NotFoundError`); time/ids via `@edge-git/shared/utils` (`TimestampUtil`, `UUIDUtil`, `CryptoUtil`, `EmailAddress`, `RepoFullName`, `Result`).
