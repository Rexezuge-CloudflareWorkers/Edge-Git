# Edge-Git — Backend Services

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Layer 3 (may use layers 0–2 only, never apps).

- Domain map:
  - `src/auth/AccessAuthService.ts` — `/user/*` identity: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access.getIdentity()` fallback. Never trust `Cf-Access-Authenticated-User-Email`.
  - `src/auth/TokenService.ts` — PATs: `sha256("edge-git-pat:" + token)`, `MAX_TOKENS_PER_USER` (default 5), `MAX_TOKEN_EXPIRY_DAYS`; mint/authenticate (`authenticateWithPAT` → `{email, scopes}` + `last_used_at` touch)/list/revoke. Scopes (`TokenScopes.ts`: `repo:read|repo:write|admin`, `admin` > `write` > `read` hierarchy, legacy NULL rows = full) are git-only: fetch needs `repo:read`, push needs `repo:write` (enforced in `gitAuthForRepo`).
  - `src/protection/BranchProtectionService.ts` — per-repo `*`-glob rules (longest match wins): `require_pr`, `required_approvals` 0–6 (creator self-approval excluded, `checkMergeBlocked` shared by same-repo + cross-fork merges; dismissed reviews never count), `block_force_push`/`block_deletion` (DO-enforced via RPC protections), CODEOWNERS quorum (resolved owners for the changed paths need one non-creator owner approval), `require_status_checks` stored-but-ignored. `MAX_RULES_PER_REPO` (default 10).
  - `src/repo/RepoService.ts` — repo CRUD by `(owner, name)` (case-insensitive): `normalizeOwner/normalizeRepo` (strip `.git`), `validateNames`, `requireRole(read|write|admin)` (private hides existence → 404), `listVisibleForUser` (owned + org-visible + collaborated), org-create allowed for owners + members, `MAX_REPOS_PER_USER`. Delete cascades issues + collaborators.
  - `src/user/UserService.ts` — `upsertUser` (lowercased email, idempotent; bootstraps globally-unique `username` from email prefix + `namespaces` claim) + `getProfileByEmail/getByUsername/renameUsername` (validates `OWNER_RE`, cascades `repositories.owner`, frees old name immediately).
  - `src/org/OrganizationService.ts` — org CRUD + `owner|member` management: `createOrganization` (global-namespace check), `requireOwner/requireMember`, `addMember/setMemberRole/removeMember` (last-owner guard), `rename` (cascades repos), `disband` (blocked while repos exist), `resolveEmail(usernameOrEmail)`.
  - `src/permission/PermissionService.ts` — central `getRole(viewerEmail|null, repo)` → `admin|write|read|null`: org owners implicit admin, members/outsiders via `repo_collaborators`, anon read-only on public. Used by git auth, public visibility, repo/issue guards.
  - `src/issue/IssueService.ts` — per-repo auto-numbering (`MAX(number)+1`), newest-first `listByRepo`. Triage (`updateStatus`) requires `write+` (enforced in routes via `requireRole`).
  - `src/pull/PullRequestService.ts` — PR CRUD + reviews/comments + inline threads (`openThread/replyThread/resolveThread`, path/line/side validation, 10k body caps) + `dismissReview` (`write+` in routes; dismissed reviews stay visible but leave `isBlockedByReviews`/quorum).
  - `src/collab/Codeowners.ts` — `parseCodeowners/matchCodeowners` + `normalizeCodeownerHandle` (`@user`→username, teams/unresolvable→null for the API to skip).
  - `src/search/SearchService.ts` — `searchRepos/searchIssues/searchPulls/searchCode` (`sanitizeQuery` 2–200 chars, `clampLimit` ≤50, over-fetch ×3 then `PermissionService` visibility filter).
  - `src/webhook/WebhookService.ts` — hook CRUD (`MAX_HOOKS_PER_REPO` default 10): URL SSRF guard (http/https, no credentials, no literal loopback/private hosts), event subset of `WEBHOOK_EVENTS`, per-hook unique signing secret (auto-generated or caller-provided 16–256 chars; masked in lists, once on create/rotate).
  - `src/webhook/WebhookDeliveryService.ts` — at-least-once fan-out: `enqueueForEvent` (active + subscribed hooks only, never throws), `processDue` (optimistic per-row claim, `AbortSignal` timeout, HMAC `X-EdgeGit-Signature-256`, retry 429/5xx + network with 1m→24h backoff, `WEBHOOK_MAX_ATTEMPTS` default 5, hook auto-disable after `WEBHOOK_MAX_CONSECUTIVE_FAILURES` default 20), `sendTestPing` (inline `ping`), `redeliver`, prune passthrough.
- `src/composition/` — `Tokens` registry (`tokens.ts`: `Env/Db/Keys/AppConfig`, DAO factories, services) + `createRequestScope(env)` (`requestScope.ts`): per-request `Container`, memoized `Keys`/DAO factories (no Secrets Store round-trip until used), lazy `AppConfig`. Handlers resolve `scope.get(Tokens.X)`; the old `*Factory` shims were removed.
- Constructor injection: every service takes `(env, deps?)` with `() => Promise<DAO>` factories defaulting to real DAOs — tests override with fakes (see `test/composition.test.ts`), no module mocks needed.
- Errors via `@edge-git/backend-errors` (`Bad/Unauthorized/Forbidden/NotFoundError`); time/ids via `@edge-git/shared/utils` (`TimestampUtil`, `UUIDUtil`, `CryptoUtil`).
