# Edge-Git — Backend Services

Scope: `packages/backend-services/**`. Parent index: `../../AGENTS.md`. Layer 3 (may use layers 0–2 only, never apps).

- Domain map:
  - `src/auth/AccessAuthService.ts` — `/user/*` identity: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access.getIdentity()` fallback. Never trust `Cf-Access-Authenticated-User-Email`.
  - `src/auth/TokenService.ts` — PATs: `sha256("edge-git-pat:" + token)`, `MAX_TOKENS_PER_USER` (default 5), `MAX_TOKEN_EXPIRY_DAYS`; mint/authenticate (`authenticateWithPAT` → `{email, scopes}` + `last_used_at` touch)/list/revoke. Scopes (`TokenScopes.ts`: `repo:read|repo:write|admin`, `admin` > `write` > `read` hierarchy, legacy NULL rows = full) are git-only: fetch needs `repo:read`, push needs `repo:write` (enforced in `gitAuthForRepo`).
  - `src/protection/BranchProtectionService.ts` — per-repo `*`-glob rules (longest match wins): `require_pr`, `required_approvals` 0–6 (creator self-approval excluded, `checkMergeBlocked` shared by same-repo + cross-fork merges), `block_force_push`/`block_deletion` (DO-enforced via RPC protections), `require_status_checks` stored-but-ignored. `MAX_RULES_PER_REPO` (default 10).
  - `src/repo/RepoService.ts` — repo CRUD by `(owner, name)` (case-insensitive): `normalizeOwner/normalizeRepo` (strip `.git`), `validateNames`, `requireRole(read|write|admin)` (private hides existence → 404), `listVisibleForUser` (owned + org-visible + collaborated), org-create allowed for owners + members, `MAX_REPOS_PER_USER`. Delete cascades issues + collaborators.
  - `src/user/UserService.ts` — `upsertUser` (lowercased email, idempotent; bootstraps globally-unique `username` from email prefix + `namespaces` claim) + `getProfileByEmail/getByUsername/renameUsername` (validates `OWNER_RE`, cascades `repositories.owner`, frees old name immediately) + `updateProfile`.
  - `src/org/OrganizationService.ts` — org CRUD + `owner|member` management: `createOrganization` (global-namespace check), `requireOwner/requireMember`, `addMember/setMemberRole/removeMember` (last-owner guard), `rename` (cascades repos), `disband` (blocked while repos exist), `resolveEmail(usernameOrEmail)`.
  - `src/permission/PermissionService.ts` — central `getRole(viewerEmail|null, repo)` → `admin|write|read|null`: org owners implicit admin, members/outsiders via `repo_collaborators`, anon read-only on public. Used by git auth, public visibility, repo/issue guards.
  - `src/issue/IssueService.ts` — per-repo auto-numbering (`MAX(number)+1`), newest-first `listByRepo`. Triage (`updateStatus`) requires `write+` (enforced in routes via `requireRole`).
- `src/composition/` — `Tokens` registry (`tokens.ts`: `Env/Db/Keys/AppConfig`, DAO factories, services) + `createRequestScope(env)` (`requestScope.ts`): per-request `Container`, memoized `Keys`/DAO factories (no Secrets Store round-trip until used), lazy `AppConfig`. Handlers resolve `scope.get(Tokens.X)`; `*Factory.create({ DB })` re-exports in `composition/index.ts` are deprecated shims.
- Constructor injection: every service takes `(env, deps?)` with `() => Promise<DAO>` factories defaulting to real DAOs — tests override with fakes (see `test/composition.test.ts`), no module mocks needed.
- Errors via `@edge-git/backend-errors` (`Bad/Unauthorized/Forbidden/NotFoundError`); time/ids via `@edge-git/shared/utils` (`TimestampUtil`, `UUIDUtil`, `CryptoUtil`).
