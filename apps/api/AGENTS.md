# Edge-Git — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — `fetch`/`scheduled` via `EdgeGitWorker`; re-exports `CronTasksWorker`, `RepoWorker` from `@edge-git/background` for DO bindings.
- `src/workers/EdgeGitWorker.ts` — Hono routes (no Chanfana file-routing; `endpoints/git|user/` are empty placeholders). `src/types.d.ts` — global `Env`.
- `src/workers/repoStub.ts` — `getRepoStub(env, fullName)` (`REPO.getByName`) + `ensureRepo`; DO RPC for branches/tree/blob/commits and pack fetch/push.
- `src/middleware/` — `MiddlewareHandlers.userAuthentication()` (`/user/*`) + `gitAuthForRepo()` (Smart HTTP; sets `AuthenticatedUserEmailAddress` on PAT success) + `activityAudit()` (audit-everything: records all `/user/*` incl. denied requests + `git-receive-pack` pushes via `waitUntil`, never throws; fetches/public reads unaudited) + `webhookFlush()` (immediate webhook dispatch via `waitUntil` after mutating `/user/*` + `git-receive-pack` requests; reads never flush); never trust `Cf-Access-Authenticated-User-Email`.
- `src/generated/spa-shell.ts` — generated by web build; do not edit.

## Auth

- `/user/*` — Cloudflare Access via `AccessAuthService`: `DEMO_MODE` → `DEV_AUTH_EMAIL` → JWT (`cf-access-jwt-assertion` vs `TEAM_DOMAIN`/`POLICY_AUD`) → `ctx.access` fallback; upserts user (email login, username bootstrap) on success.
- Git Smart HTTP stays outside Access: anonymous `read` only for public `git-upload-pack`; private fetch needs `read`, all `git-receive-pack` needs `write+` via PAT (Basic password or Bearer, `TokenService.authenticateWithPAT` → `{email, scopes}` → `PermissionService.getRole`). PAT scope gate: fetch needs `repo:read`, push needs `repo:write` (`coversScope` hierarchy; 403 on insufficiency). Private repos hide existence (401, not 404, on git paths). Push commands additionally pass D1-resolved branch protections into the DO (`receivePack(data, protections)`); force-push ancestry is checked post-index.
- Public read-model (`/repos/*`): anonymous OK for public repos, private → `404` unless viewer has `read+` (viewer resolved best-effort via Access or PAT, never throws). `requireVisibleRepo`/`requireRoleForRepo` delegate to `PermissionService`.

## Routes

- Git (`EdgeGitWorker`, exact matches so SPA catch-all never intercepts): `GET /:owner/:repo/info/refs?service=git-upload-pack|git-receive-pack` · `POST /:owner/:repo/git-upload-pack` (413 over fetch limit) · `POST /:owner/:repo/git-receive-pack` (413 over pack limit).
- Public: `GET /repos/:owner/:repo|/branches|/tree|/blob|/commits|/issues|/issues/:number|/issues/:number/comments|/releases|/releases/:tag|/releases/:tag/assets` (+ asset `.../assets/:assetId/download` binary) · `GET /users/:username` (user or org profile) · `GET /health` · `/docs` (Chanfana `fromHono`).
- Protected (`/user/*`): `GET /user/me` (`{email,username}`) · `PATCH /user/me/username` (cascades repos, best-effort DO move, frees old name) · `GET|POST /user/repos` (owner defaults to self username; org owner must be org where caller is owner|member) · `GET|PATCH|DELETE /user/repos/:owner/:repo` (`admin` for write ops, `viewerRole/viewerCanManage` in reads) (+ `/branches|/tree|/blob|/commits` DO passthroughs) · `POST /user/repos/:owner/:repo/branches` (`write+`; delete 403 on `blockDeletion` rule) · `GET|POST|DELETE /user/repos/:owner/:repo/rules[/:id]` (list `read+`, mutate `admin`) · `POST /user/repos/:owner/:repo/contents` (upsert text file, `201` on create; 403 on `require_pr` branch) · `DELETE /user/repos/:owner/:repo/contents?branch=&path=` (file delete; both `write+`, optional `expectedOid` → 409; 403 on `require_pr` branch) · `GET|PUT|DELETE /user/repos/:owner/:repo/collaborators[/:member]` (`admin`-only, `admin|write|read`) · `POST|GET|PATCH|DELETE /user/orgs[/:org[/members[/:member]]]` (member mgmt `owner`-only, last-owner guard) · `GET|POST|DELETE /user/tokens` (POST accepts `scopes?` subset of `repo:read|repo:write|admin` + `expiresInDays?`) · `GET|POST /user/.../issues`, `GET|PATCH /user/.../issues/:number` (`write+` to triage) · `GET|POST /user/.../issues/:number/comments` · `GET|POST /user/.../pulls`, `GET|PATCH /user/.../pulls/:number` (`write+` to triage; list supports `?label=&q=`) · `GET|POST /user/.../pulls/:number/comments|reviews` · `POST /user/.../pulls/:number/reviews/:reviewId/dismiss` (`write+`; dismissed reviews stay visible but leave the gate) · `GET|POST /user/.../pulls/:number/threads[/:threadId/replies]` + `PATCH .../threads/:threadId` (`{resolved}`; resolve needs author or `write+`) · `GET /user/.../pulls/:number/codeowners` (suggest; PR creation auto-requests resolved owners best-effort) · `POST /user/.../pulls/:number/merge` (`write+`; 409 on `changes_requested`, unmet `requiredApprovals`, or missing code-owner approval for the protected base).
- SPA: `/` + `/user/` redirect + `*` catch-all always serves `SPA_HTML`; `/:owner/:repo` serves shell, unknown paths `404`.

## Composition

- Single scope per request: `scopeMiddleware` installs one `Container` + `ServiceContext`; handlers resolve via `getScope(c).get(Tokens.X)` (`PublicViewerResolver.getScope` falls back to `createRequestScope` for helpers/tests). The old `*Factory` shims were removed.
- `src/endpoints/IBaseRoute.ts` — `BaseRoute` template method (`handle()` → `handleRequest()` + `toErrorResponse()` mapping `ServiceError`; untyped masked as 500; wires `getBackendStrings`).
- `PublicViewerResolver` unifies `withPublicRepo` + `withVisibleRepo` + `requireVisibleRepo`/`requireRoleForRepo` (private hides existence → 404); `RepoRoutes` authed read-model delegates to it (no local duplicate).
- Never import `@edge-git/backend-data/dao` values in routes (type-only allowed, enforced); never import `@edge-git/git-service` directly — use `@edge-git/git-protocol` builders/parsers + DO RPC.
- Route modules stay under the god-file guard (soft 300 / hard 400 LOC, warn-only): `collab/` holds the split `Label|Milestone|IssueTriage|PullTriage|ForkSync|BlameRoutes`; PR threads/dismiss live in `PullThreadRoutes.ts`, CODEOWNERS suggest/resolve in `CodeownerHelpers.ts` (`org/team` tokens expand via `TeamService.listMemberEmails`); webhooks live in `WebhookRoutes.ts` (CRUD + rotate/test/deliveries/redeliver, list `read+`, mutate `admin`, secrets masked except one-time create/rotate); releases live in `ReleaseRoutes.ts` (CRUD, drafts hidden from non-`write+`, publish requires the git tag) + `ReleaseAssetRoutes.ts` (upload `write+` base64 → DO bytes, binary download `read+`); teams live in `TeamRoutes.ts` (org member reads, org-owner create/rename/delete/grants, owner-or-team-admin member mgmt); audit readers live in `AuditRoutes.ts` (`GET /user/orgs/:org/audit` owner-only + `GET /user/audit` personal, cursor-paginated); realtime tickets/upgrade live in `RealtimeRoutes.ts` (public `GET /realtime/ws` ticket-gated upgrade + authed `POST /user/realtime/ticket` / `GET /user/realtime/inbox-ticket` via `RealtimeService`), fan-out helpers in `SocialEmit.ts` (`publishLiveUpdate` for repo/inbox shards + `publishCheckUpdate` for per-SHA check channels; both best-effort, disabled unless `REALTIME_ENABLED=true`); `realtimeStub.ts` resolves `REALTIME.getByName(shard)`.
